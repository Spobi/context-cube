# Example

`tidepool/` is a small made-up project (a note-syncing app) after `npx context-cube` built its cube. Its original memory files, `CLAUDE.md`, `CONSTITUTION.md`, and `NOTES.md`, sit next to the cube they were built from; the build didn't change them, apart from the always-loaded block it added at the end of `CLAUDE.md`.

Start at `tidepool/context-cube/CUBE.md`, then open a row index such as `tidepool/context-cube/Y02-invariants/ROW.md`. The tool's own copy (`context-cube/.tool/`) and the logs (`context-cube/.logs/`) are left out of the example.
